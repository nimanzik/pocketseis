# PocketSeis

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
[![Python](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)

**PocketSeis** is a Python toolkit for seismological analysis and computation. It provides a collection of utilities and functions to facilitate common tasks in seismological research, including moment tensor operations, coordinate transformations, waveform processing, and specialized plotting capabilities.

## Installation

```bash
git clone https://github.com/nimanzik/pocketseis.git
cd pocketseis
pip install .
```

For development installation:

```bash
pip install --editable .
```
